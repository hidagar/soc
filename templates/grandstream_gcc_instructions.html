1. En la barra superior, entra en el módulo Networking (icono del globo) y abre Maintenance → System Diagnostics → Syslog. No uses Home → Logs & Diagnostics → System Logs: ese apartado envía solo registros de Home.
  2. En Server Address, introduce {{ gcc_destination }}:{{ gcc_port }} y deja Protocol: UDP.
  3. En Target Devices, selecciona el GCC que estás configurando. Esta exportación cubre los módulos Networking, Network Nodes y Firewall. Usa Warning para empezar con eventos relevantes; selecciona Information solo si necesitas más detalle y puedes asumir el volumen adicional. Evita Debug permanente.
  4. Pulsa Save. Luego comprueba en el SOC la recepción y el primer evento del equipo. La llegada de mensajes Home no confirma que los eventos Firewall/IDS se estén exportando.

Seguridad pendiente de validar: comprobar un registro de actividad no confirma la interpretación de IDS/IPS o antimalware. Revisa licencia, módulos y formato de una alerta real antes de incluir ataques en los informes. Los registros de telefonía/PBX se configuran por separado.

Esta integración usa Syslog guiado, sin credenciales API ni SSH. Para IP dinámica, elige el envío HTTPS del asistente: el GCC envía por UDP al reenviador local y este se autentica ante el SOC. El receptor directo actual usa UDP; no selecciones TCP o TLS para ese destino.
