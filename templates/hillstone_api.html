Preparar Hillstone

  1. Crea un usuario dedicado con los permisos mínimos para consultar el sistema.
  2. Permite HTTPS de gestión desde la IP del servidor SOC por vuestra red privada o VPN.
  3. Introduce la URL y las credenciales aquí. Si el certificado usa una CA privada, pega su certificado PEM.
  4. Guarda y pulsa «Comprobar acceso y descubrir equipo».

Perfil REST documentado para StoneOS 5.5R6P9: usuario y contraseña codificados en base64 dentro de HTTPS. Otras versiones requieren comprobar compatibilidad. La prueba no modifica políticas ni configura syslog.
