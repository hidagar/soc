Ahora configura Zenarmor

OPNsense y Zenarmor exportan sus registros por separado. Aunque hayas utilizado API o SSH, completa también este apartado en Zenarmor.

  1. Abre Zenarmor → Settings → Reporting & Data → Streaming Data.
  2. Activa Stream Reporting Data to Syslog.
  3. Introduce la IP del servidor indicada arriba, puerto {{ port }} y protocolo UDP. Utiliza la misma ruta y la misma IP de origen que OPNsense.
  4. Selecciona Alerts y pulsa Save & Enable. Para comprobar la recepción con navegación normal, puedes añadir temporalmente Connections y retirarlo después.
No aparece Streaming Data o no me permite activarlo

La exportación Syslog requiere Zenarmor SOHO o Business. Las ediciones Free y Home no incluyen esta función. Puedes volver a «Conexión» y elegir el perfil OPNsense para conectar sus logs generales mientras resuelves la exportación de Zenarmor.

Si la base de informes de Zenarmor está detenida o muestra un error, revisa su estado antes de comprobar la exportación.
